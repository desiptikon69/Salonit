## Полнота и формат

- [salon-os.full.txt](salon-os.full.txt) — весь текст без сокращений; 131 491 единица UTF-16.
- [google-doc.snapshot.json](google-doc.snapshot.json) — полный структурированный ответ Google Docs: текст, ссылки, стили, исходные индексы, свойства вкладки и документа.
- [manifest.json](manifest.json) — ID, ревизия, состав, пути и SHA-256 исходных файлов.
- [PRODUCT_CONFIG](../product-config.source.json) — JSON конфигурации, дословно извлеченный из раздела 5 по значениям; статусы CONFIRMED/RECOMMENDED/CANDIDATE/TBD/ASSUMPTION сохранены.
- [Проверка переноса](../verification.json) — фактически выполненные проверки, не тесты будущего приложения.

В источнике одна вкладка, 1 385 абзацев, таблиц и встроенных изображений нет. Ссылки и форматирование сохранены в JSON. Внешние сайты из реестра S01–S60 и содержимое Figma/ FigJam в этот снимок не входят. Перенесены их ссылки и описания из самого Google Doc; текущая доступность и достоверность внешних материалов отдельно не проверены.

## Важное различие идентификаторов

F01–F18 раздела 4 — исследовательские выводы. F01–F03 раздела 10 — будущие сценарии приемки. Это разные наборы; в рабочих ссылках указывать раздел или пространство имен research/future-acceptance.

Ни один сценарий Axx из исходника не считается проведенным тестом приложения. Ни один статус CONFIRMED из снимка не означает новый ответ пользователя в текущем чате: это перенесенное решение из источника, которое сохраняется до явного изменения.

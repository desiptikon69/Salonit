# P16 · ИИ — только будущий отдельный этап

PROMPT BEGIN P16
Этот промпт выполняется только после отдельного включения AI-модуля. Пользователь прямо исключил ИИ из первой версии. До этого не добавляй обязательные LLM-зависимости, чат, платные токены или AI-администратора в клиентский путь.

После включения спроектируй помощь: поиск по разрешенным данным, сводки, объяснение показателя, черновики сообщений и рекомендации. Для каждой функции покажи роль, данные, поставщика, географию обработки, цель, затраты, ограничения, оценку и возможность отключить.

ИИ не создает свою цену, длительность, квалификацию, остаток, медицинское решение или уверенность в эффекте. Такие данные берутся из серверного домена с учетом актуальной версии. Retrieval, tools и память проверяют tenant/branch/field permissions; сообщение клиента и сторонняя страница — недоверенные данные, не инструкции системе.

Рекомендация показывает наблюдение/период, исходные операции, допущения, недостающие данные, сценарный эффект, предлагаемое действие и уполномоченного человека. Расхождение материалов не превращается в обвинение в краже. Цена, закупка, возврат, зарплата, удержание, доступ и кадровое решение требуют предусмотренного полномочия/утверждения, а не самовольного действия модели.

Если разрешена рутинная запись, ИИ использует тот же booking engine, атомарную проверку и согласованные правила. Неудача/неопределенность передается человеку. Возможности исполнения ограничены серверным инструментом, бюджетом и политикой; нельзя обходить подтверждение через другое API.

Настрой журнал модели/версии/источников/действий без лишних персональных данных, лимиты стоимости, ручной takeover и kill switch. Не отправляй реальные клиентские/медицинские сведения внешнему поставщику без проверенной законной конфигурации. Демо не получает реальные доступы.

Проверь утечку между салонами, prompt injection в заметке клиента, выдуманную цену, устаревший слот, отказ пользователя, малую выборку и повтор инструмента. Приемка: ИИ улучшает согласованный измеримый процесс и не ухудшает точность/контроль. Если надежность или экономика не подтверждены, модуль остается выключенным.

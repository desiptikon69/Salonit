# 2. Как использовать пакет

Для начала нового проекта передай исполнителю раздел PRODUCT_CONFIG, 33 правила и полный P00, затем P22 для первого демо. Если исполнитель может читать прикрепленный документ, приложи весь пакет и укажи нужный этап. Ссылка сама по себе не гарантирует, что модель прочитала содержимое.

Для реализации конкретного модуля передавай P00/актуальный config, соответствующий Pxx и связанные сценарии приемки. Не запускай все 23 промпта одновременно: у модулей общий контракт данных. P00 руководит проектом, остальные задают конкретную работу.

PROMPT BEGIN/END — границы копирования. Требования будущих модулей условны. ИИ, онлайн-платежи, сеть/аренда, другие страны и медицинский контур не включаются ради полноты.

После каждого этапа исполнитель сохраняет конфигурацию, решения, требования, выполненные проверки и следующий шаг в docs/product. При продолжении перечитывает эти файлы, не начинает заново.



## Этап A: точное основание

P00 → P01 → P18 (только уточнение услуг) → P02 → P03

Config, бизнес-правила, модель, роли, экранные сценарии, приемка. Медицинская реализация только при подтвержденной необходимости.



## Этап DEMO: показать клиенту

P22 после P00/P01/P02/P03; нужные части P04–P12 и P14/P17

Вымышленный салон, сквозная запись → услуга → закрытие → зарплата/материалы/расходы. Ссылку для показа пользователь организует сам. Демо не считается live-пилотом.



## Этап B: клиентская запись и отдельные копии

P04 → P17 (ядро инсталляций) → P05 → P06 → P07

OTP гостя, параллельный/последовательный визит, серверная занятость, перенос, календарь и реестр копий.



## Этап C: полный рабочий день

P08 → P09 → P11 → P12 → P10

Факт услуги, ручная регистрация оплаты в салоне, объяснимое начисление, материалы, расходы и отчет.



## Этап D: эксплуатация и качество

P13 → P14 (базовые повторы/рекомендации) → P15 → P19 → P20 → P21

Переделки/задачи, рекомендации, импорт/уведомления, защита, резервирование, пилот и исправления.



## Этап E: развитие

Расширения P14/P17; медицинская реализация P18 по необходимости; P16 только после включения ИИ

Кампании, сеть, аренда, другие страны. ИИ и онлайн-платежи отсутствуют в первом релизе.
